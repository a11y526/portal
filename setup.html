설치 도우미

과학 수업 포털을 내 서버로 처음 설정하는 화면이에요. 위에서부터 차례로 하면 됩니다.

0

준비

  1. GitHub: 원래 포털 저장소에서 오른쪽 위 Fork → Create fork.
  2. 내 저장소 Settings → Pages에서 Branch를 main, 폴더를 /(root)로 고르고 Save. 몇 분 뒤 위쪽에 사이트 주소가 뜹니다. 지금 보고 있는 이 화면은 그 주소의 setup.html이어야 해요.
  3. Supabase(supabase.com) 가입 → New project. Region은 Northeast Asia (Seoul). 데이터베이스 비밀번호는 따로 적어 둡니다.

5번을 마치기 전까지 내 사이트는 원래 사이트의 서버에 연결되어 있어요. 학생에게 주소를 알려 주는 것은 5번을 끝낸 뒤에 합니다.

내 Supabase 서버 연결

아직
  1. Supabase 프로젝트 화면 위쪽 Connect 버튼(또는 왼쪽 아래 Project Settings → API Keys)을 엽니다.
  2. Project URL(https://…supabase.co)과 Publishable key(sb_publishable_로 시작)를 복사해 아래에 붙여 넣습니다. 예전 화면이면 anon public 키를 씁니다.
  3. secret·service_role 키는 절대 넣지 않습니다.

3

서버에 설치하기

아직
  1. 위 복사를 누릅니다.
  2. Supabase 왼쪽 메뉴 SQL Editor(>_ 모양) → + New query(또는 빈 입력 칸).
  3. 붙여 넣고(⌘V 또는 Ctrl+V) 오른쪽 아래 Run. 길어서 1분쯤 걸릴 수 있어요. 아래에 Success가 뜨면 됩니다. "destructive operation" 확인 창이 뜨면 Run this query.
  4. 여기로 돌아와 설치 확인.
