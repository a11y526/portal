# 과학 수업 포털 (게임 없는 판)

중학교 과학 수업용 웹사이트예요. 학생은 반·번호·코드로 들어와 개인 학습지·모둠활동·퀴즈를 하고, 선생님은 관리 화면에서 수업을 진행합니다.

## 설치 (윈도우, 처음 한 번)

준비: [GitHub](https://github.com/signup)와 [Supabase](https://supabase.com/dashboard/sign-up)에 가입만 해 두세요.

1. 위 파일 목록에서 `install` → `설치.bat`을 누르고, 오른쪽 위 **내려받기(Download raw file)** 단추로 받습니다.
2. 받은 `설치.bat`을 두 번 누릅니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**.
3. 검은 창이 묻는 대로 담당 반, 선생님 체험 코드(숫자 6자리), 관리 화면 이메일·비밀번호를 넣고, 브라우저에 열리는 화면에서 GitHub·Supabase 토큰을 만들어 붙여 넣습니다.
4. 10~20분 뒤 "설치 끝"이 나오면 바탕화면의 `과학 포털 주소.txt`에 학생 입구·관리 화면 주소가 있어요.

학교 컴퓨터에서 실행이 막히면 집 컴퓨터에서 하면 돼요(설치는 한 번만, 그 뒤로는 어느 컴퓨터든 크롬으로 주소만 열면 됨).

## 새 기능

원래 포털에 새 기능이 생기면 매일 새벽 2시쯤 저절로 들어와요. 따로 할 일은 없어요.
