수업 하루

  1. 수업 모드 열기관리 [수업 시작], 차시 카드 [수업 시작], 반 선택. 프로젝터 화면으로 옮기고 F
  2. 설명← → 로 넘김. 학생 학습지도 같은 쪽으로 넘어감 (아직 못 씀)
  3. 학생 쓰기쓰게 할 쪽에서 S. 학생이 쓰고 쪽 제출
  4. 답 보기V. Enter 인정, N 넘기기
  5. 모둠활동G, 모둠 편성. 학생이 게시판에 올리고 제출. 휴대폰 검사에서 통과·다시
  6. 순위 발표G 화면 [순위 발표]. 이때 점수 지급. G로 수업자료로 돌아감

학기 처음

  1. 학생 → 명단과 코드: 반별 마지막 번호 입력, [명단 저장]
  2. 첫 시간: 그 반 탭 [가입 열기] (그날 밤 12시까지)
  3. 칠판에 사이트 주소. 학생은 [처음 가입]에서 학번·코드로 가입
  4. '가입 n / N명' 다 차면 [가입 닫기]
  5. 학생 [바로가기 만들기]로 크롬 새 탭 바로가기
  6. 학생 안내(위 단추)를 [화면으로 보기]로 띄워 설명
  • 잘못 가입한 번호, 코드 잊은 학생: 그 번호 [코드 다시 발급]
  • 코드를 종이로 나눠 주려면: [코드 없는 학생 발급] (A4 인쇄)
  • 0번: 반마다 있는 선생님 체험 계정. 설치 때 정한 코드. 순위에 안 나옴

수업 전

  • 새 차시: 수업 → 수업 시작 → [+ 차시 추가], 차시 창에 수업자료 주소 [저장]
  • 웹 학습지(정답 포함): 공유 자료실에서 받아 차시 창 [학습지 올리기]. 저절로 들어오지 않음
  • 확인: 차시 카드의 반 칩 = 그 반 보드 있음. 없으면 보드 → [+ 새 보드]
  • 고치기: 수업 → 보드 (모둠 학습지, 보관 등)

수업 시작

  1. 관리 오른쪽 위 [수업 시작]
  2. 차시 카드 [수업 시작], 반 번호
  3. 수업 모드 창을 프로젝터로, F
  4. 학생: [수업] → 개인 학습지
  • 수업 모드가 켜져 있을 때만 학생이 학습지를 씀
  • 위 띠 '딴 화면 n명' = 포털 밖으로 나간 학생 수 (기록만, 감점 없음)

학습지 조절

← →쪽 넘기기. 학생 학습지도 따라 넘어감
S지금 쪽 쓰기·제출 열기. 다시 누르면 잠그기, 또 누르면 다시 열기 (쓴 답은 남음)
O이 쪽 열어 두기. 학생이 다른 쪽에서도 넘겨 볼 수 있음
A수업자료 답 보기
W남은 쪽 모두 열기
⇧ W지금 쪽까지로 되돌리기
  • 시뮬레이션도 S로 연 쪽에서만 움직임
  • 마지막 쪽에 5초 있으면 수업 끝, 모든 쪽 열림
  • 위 띠 '학습지 완료 n / N' = 다 낸 학생 수
  • [모둠 학습지 켬]: 모둠당 노트북 1대일 때. 한 명이 쓰면 모둠원 모두에게 기록 (모둠 편성 뒤)

첫 답 (V)

  • S 뒤 50초 안에 낸 학생 중에서 추첨. 이번 달 덜 뽑힌 학생 먼저
  • V: 뽑힌 답 크게 (닉네임만)
  • Enter 인정 (보너스, 쪽마다 1명) / N 넘기기 / B 이전 / Esc 닫기
  • 잘못 인정: 띠 [인정 취소]

모둠활동 · 발표 (G)

G: 수업자료 위에 모둠 화면. 다시 G 누르면 보던 쪽 그대로.

1 모둠편성: 모둠 수, 결석생 빼기, [섞기], 저장. 편성 뒤 모둠 카드. 통과도 '검사 대기'로 보임 (발표 때 공개)
2 게시판모둠별 글 수. 발표 전에는 [보기] 누른 칸만 프로젝터에
3 순위 발표[순위 발표], 스페이스로 3위·2위·1위. 이때 통과 모둠 점수 지급. 잘못 누르면 [발표 취소]
4 퀴즈 쇼만들어 둔 퀴즈 쇼 골라 시작
  • 학생: 모둠 게시판에 올리고 한 명이 제출
  • 교사: 휴대폰 검사에서 게시물 보고 [통과] / [다시] + 메모
  • 순위 = 통과된 제출의 제출 시각 순 (검사가 늦어도 그대로)
  • 첫 제출 뒤에는 편성 다시 못 함

퀴즈

  • 퀴즈 배틀: G, 모둠 탭 아래 [퀴즈 배틀 열기]. 모둠끼리 오늘 학습지 문제 20개, 문제당 10초, 모둠 1등만 점수
  • 퀴즈 쇼 만들기: 수업 → 퀴즈 쇼 (학습지에서 가져오기 가능)
  • 퀴즈 쇼 진행: G, 4 퀴즈 쇼, 골라서 시작, 스페이스로 다음. 학생은 퀴즈 쇼 탭. 1~3위 점수

휴대폰

  • 검사 (위 메뉴): 제출이 들어온 순서대로 쌓임. 관리와 같은 계정으로 로그인
  • 휴대폰 리모컨 (수업 → 휴대폰 리모컨): 쪽 넘기기, 답 보기, G, S, V, 인정·넘기기, 발표 다음. 수업 모드가 켜져 있어야 함

점수 · 상점

  • XP: 레벨, 이번 달 순위 / 금화: 보상 (승인 필요) / 은화: XP만큼 쌓임, 꾸미기
  • 포인트 규칙: 모둠 통과, 순위 보너스, 학습지 완료, 첫 답, 퀴즈 점수
  • 구매 승인: 보상 승인·거절 (거절하면 금화 돌려줌). 모둠 선택권은 승인하면 편성 때 둘이 같은 모둠
  • 점수 주기: 학생 골라 XP·금화 주기/빼기, 사유 필수
  • 금화 현황, 상점 설정(가격·판매), 닉네임(신청 승인. 승인 전 '닉네임 미정')

그 밖의 메뉴

  • 반 게시판: 반별 또는 모든 반 공통 자료, 링크, 유튜브, PDF
  • 반별 잠금: 잠그면 로그인 불가, 모두 로그아웃
  • 진도 관리: 시간표 넣으면 반별 진도, 남은 수업
  • 빠른 피드백 단추: 검사 [다시]에 쓰는 문구
  • 기록 내보내기 · 정리: 점수 기록 CSV, 학기 끝 보드 보관
